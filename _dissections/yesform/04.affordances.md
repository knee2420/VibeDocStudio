# 예스폼 클릭·호버 어포던스 명세

> **수집**: 2026-10-28, 디버그 Chrome(9222)에 실제 마우스 입력(CDP `Input.dispatchMouseEvent`)을 보내 견적서 템플릿 복제본에서 측정했습니다.
> **방법**: 조작 전과 후의 화면 요소 전체(위치·클래스·스타일)를 비교해서 새로 생긴 요소만 뽑았습니다. 툴바와 사이드바는 비교 대상에서 뺐습니다.
> 03 문서에서 "표 위 호버 시 오버레이 없음"이라고 적은 것은 잘못된 기록이었습니다. 당시에는 표가 화면 밖에 있어서 관찰되지 않았습니다. 이 문서가 그 내용을 대체합니다.

## 1. 표 (table)

### 호버 시 나타나는 요소 (모두 `position:absolute; z-index:33`, 문서 영역 안에 렌더링)

| 요소 (클래스) | 위치·크기 | 모양 | 커서 / 툴팁 | 동작 |
|---|---|---|---|---|
| `table-move-grip` | 표 왼쪽 위 바깥 (-26px, 0), 16×16 | 6점 그립 아이콘(점 반지름 1.4), 색 `#929292`, 배경 없음 | pointer / "표 선택" | 클릭 → 표 전체 NodeSelection. 드래그로 표를 옮기지는 못함. 우클릭 메뉴 없음 |
| `table-corner-handle` ×4 | 표 네 모서리 중심, 10×10 | 원형, 배경 `#0472e3`, 1px 흰 테두리 | nwse/nesw-resize | **오른쪽 아래만 동작**: 드래그하면 표 폭이 비율로 바뀜(`tableWidthRatio`, 602→502px, 열 비율 유지). 나머지 3개는 표시만 되고 반응 없음 |
| `table-add-row` | 표 아래 가운데, 표와 9px 간격, 42×24 | 흰 배경, 1px `#eaeaea`, 둥근 모서리 4px, + 아이콘 20px(선 1.5, `#666`) | pointer / "행 추가" | 클릭 → 표 끝에 빈 행 추가. 커서가 새 행으로 이동 |
| `table-add-col` | 표 오른쪽 바깥 세로 가운데, 24×42 | add-row와 같은 모양(세로 방향) | pointer / "열 추가" | 표 오른쪽 가장자리 근처에 마우스를 올리거나 표가 선택돼 있을 때 표시. 클릭 → 오른쪽 끝에 열 추가 |
| `resize-handle` | 열 경계선 위 | 보이지 않는 띠 | col-resize | 드래그 → 붙어 있는 두 열만 서로 너비를 주고받음(표 전체 폭 유지) |

- 표시 전환: `transition: opacity .15s, background-color .15s`
- 문단·제목·목록에 마우스를 올리면 아무것도 나타나지 않음. 블록 드래그 핸들 없음.

### 클릭·선택 상태

| 상태 | 표시 |
|---|---|
| 셀 클릭(커서가 셀 안에 있음) | 셀에 `.focused-cell` 클래스가 붙음. `::after { position:absolute; inset:-1px; border:2px solid #0472e3; pointer-events:none }` |
| 표 선택(그립 클릭) | 표 전체에 2px `#0472e3` 테두리 + 모서리 핸들 4개 + 열 추가 버튼. 툴바는 표 문맥(표 편집·칸 배경색) |
| 셀 여러 개 드래그 | CellSelection(셀 범위 하이라이트) → 우클릭 메뉴의 `셀 병합`이 활성화됨 |
| 우클릭 | 커스텀 메뉴: 셀 삽입 ▸(왼쪽에/오른쪽에/위로/아래로) · 셀 병합 · 열 너비 균등하게 · 가로 헤더 추가(헤더 행이면 "가로 헤더 해제") · 세로 헤더 추가 · 열 삭제 · 행 삭제 · 삭제 |

## 1-1. 이동 (드래그앤드롭)

> CDP의 실제 마우스 드래그로는 이 환경에서 Chrome이 네이티브 드래그를 시작하지 않았습니다. 그래서 대상 요소에 `dragstart → dragenter/dragover → drop → dragend`를 `DataTransfer`와 함께 직접 일으켜 에디터 동작을 확인했습니다.

| 대상 | 시작 방법 | 결과 | 드롭 위치 표시 |
|---|---|---|---|
| 텍스트 | 범위 선택 후 드래그 | 이동(`view.dragging.move=true`). 원래 위치에서 삭제되고 놓은 위치에 삽입 | 세로 캐럿 2px `#3b82f6`, 높이 = 줄 높이 |
| 텍스트 + Ctrl | 위와 같음 | **복사**(`move=false`). 원본 유지 | 같음 |
| 표 | `표 선택` 그립 클릭 → 표 NodeSelection → 드래그 | 블록 단위로 이동(3번째 블록이 "3. 특기 사항" 바로 앞으로 이동) | 가로 2px `#3b82f6` 선, 폭 = 본문 폭(602px) |
| 문단·제목 | 화면에 블록 손잡이 없음 | 사용자가 블록 단위로 옮길 UI 없음(NodeSelection은 코드로만 가능) | — |
| 외부 HTML | 다른 앱/영역에서 드롭 | 놓은 위치에 인라인으로 삽입 | 세로 캐럿 |
| 그립 자체 | 그립에는 `mousedown/mouseup`만 있음 | 그립을 끌어도 이동하지 않음. 그립은 "선택" 전용이고, 이동은 선택된 표를 끄는 방식 | — |

## 2. 이미지

| 상태 | 표시 |
|---|---|
| 클릭(NodeSelection) | 모서리 리사이저 4개(`image-resizer-{ne,se,sw,nw}`, 10px 원, `#3c84f4`). 드래그하면 비율 유지(`data-keep-ratio`) 상태로 `displayWidth/displayHeight`가 바뀜(300→172px) |
| 이미지 위 떠 있는 바 | `투명도` · `복사` · `삭제` (이미지 위 가운데) |
| 툴바 교체 | 기본 툴바 대신 이미지 툴바: 앞으로·뒤로(자유 배치일 때만 활성) · 왼쪽/가운데/오른쪽 정렬 · `배치 ▾`(글자처럼 취급 / 어울림 / 자리 차지 / 글 뒤로 / 글 앞으로) · 자르기 · 링크 · 그림 바꾸기 · 삭제 |

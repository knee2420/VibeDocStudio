# PandaDoc 인터랙션 (클릭·호버, 1차: 문서 변경 없음)

> **수집**: 2026-10-28, 디버그 Chrome(9222), 문서 `Sales Contract Template`(사용자 계정). 문서를 바꾸는 조작(이동·추가·저장)은 아직 하지 않았습니다.
> **정정**: `03.module_anatomy.md`의 "미니 ProseMirror 인스턴스"는 틀렸습니다. 실제 에디터는 **Slate**(`data-slate-editor` 91개)이고, 문서 본문은 `kolas-editor-iframe` 옆의 `/e/` iframe 안에 있습니다.

## 진입

- 문서를 열면 미리보기 상태입니다. 페이지 전체에 `StyledContentEditTrigger` 오버레이가 덮여 있고, 마우스를 올리면 툴팁 "Click to edit document"가 뜹니다. 클릭하면 편집 모드로 바뀌고 상단에 `Editing ▾`, 서식 툴바, **`Save changes`** 버튼이 나타납니다.

## 변수 `[Sender.Company]`, `[Client.Company]`

- `span[data-token-key][contenteditable=false]`(`data-testid=span-token-wrapper`)로 된 원자 노드이고, 배경은 노란색 하이라이트입니다.
- 표지 페이지에서는 변수가 자유 배치 텍스트 블록 안에 있어서, 클릭하면 변수 대신 **그 블록 전체가 선택**됩니다.
- 오른쪽 패널의 `Manage variables`(빨간 배지 "Fill variables 2")에서 값을 채웁니다.

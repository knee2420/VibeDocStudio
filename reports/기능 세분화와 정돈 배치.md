# 기능 세분화와 정돈 배치 (feat/relayout-nudge)

실제 앱(feat/sidebar-update)을 기능 단위로 뜯어서, 어디에 무엇이 몇 군데 있는지 세고,
"손이 갈 곳" 을 단계마다 하나로 정했다. 아무것도 지우지 않는다 — 놓는 자리와 기본값만 바꾼다 (넛지).
새 배치는 View 메뉴의 "정돈 배치" 로 켜고 끈다. 끄면 예전 화면 그대로다.

근거 틀
- 넛지 · 선택 설계: 기본값 · 놓는 순서(사과를 앞에) · 같은 길은 하나로 · 다음 할 일만 튀게 · 되돌릴 수 있게(자유는 그대로)
- 레이아웃: Z 패턴(왼쪽 위 = 지금 어디 · 무슨 단계, 오른쪽 위 = 문서 단위 행동, 오른쪽 아래 = 다음 할 일), F 패턴(왼쪽 세로줄 = 길잡이), 근접 · 공통 영역
- UX 리서치 핸드북: 11장 기능 우선순위 매트릭스 · 기능 단순화, 10장 태스크 플로우, 6장 멘탈 모델

---

## 1. 기능 목록 — 지금 자리와 겹치는 곳

| 묶음 | 기능 | 지금 자리 | 같은 일을 하는 곳 |
|---|---|---|---|
| 단계 | 1 뼈대 · 2 서식 · 3 채우기 전환 | 떠 있는 툴바 오른쪽 끝(아이콘 3개) | 1단계 작업대 "Phase 2 로 이동" 버튼 · (안 쓰이는 ExecutionPhaseStepper 컴포넌트) — **2곳** |
| AI | AI 에게 지시 | 오른쪽 AI Composer | 떠 있는 툴바 ✦ · 1단계 작업대 "AI 스토리라인 자동 스캐폴딩" · 칸 범위 AI 바 · 슬롯 서식 툴바 "이 슬롯에 AI Composer" — **4~5곳** |
| AI | AI 변경안 검토 · 승인 | 아래 검토 서랍 | 변경 기록 탭 뱃지 · 칸 옆 표시 — **2~3곳** |
| AI | 실행 중단 | 머리줄 "중단" (실행 중에만) | Esc |
| 아웃라인 | 문서 · 페이지 · 엘리먼트 트리 | 왼쪽 Layers (Documents & Pages + Elements · All) | 1단계 작업대 "내 프로젝트 스토리라인 목차" · 페이지 미리보기 패널 · 페이지 탭 — **3~4곳** |
| 아웃라인 | 노드 추가 · 이름 · 옮기기 · 들이기 | 왼쪽 트리 (Enter · Tab · F2 · Delete) | 1단계 작업대 "섹션 추가" |
| 레퍼런스 | 레퍼런스 열기 · 목차 보기 | 활동 막대 Reference 탭 | 1단계 작업대 레퍼런스 목차 · 오른쪽 리소스 탭 · Composer 칩 · 분할 뷰어 — **4~5곳** |
| 리소스 | 근거 자료 · 지식 덱 | 오른쪽 리소스 탭 | 분할 뷰 꺼내기 · Composer 칩 |
| 서식 | 서식 · 템플릿 허브 | 활동 막대 Template Hub | 2단계 작업대 |
| 에셋 | 섹션 에셋 · 블록 배치 | 활동 막대 Assets | 떠 있는 툴바 블록 넣기 |
| 칸 편집 | 글꼴 · 크기 · 굵게 … · 표 편집 | 3단계 서식 툴바 (캔버스 위) | 칸 인스펙터 |
| 칸 상세 | 슬롯 상세 · 백데이터 · 이 칸의 기록 | 오른쪽 인스펙터 탭 | 떠 있는 툴바 슬라이더 버튼 |
| 캔버스 | 선택 · 손 · 영역 · 텍스트 · 이미지 · 레이아웃 · 블록 | 떠 있는 툴바 | — |
| 캔버스 | 읽기 / 편집 모드 | 떠 있는 툴바 | — |
| 기록 | 변경 기록 · 버전 · 되돌리기 | 활동 막대 변경 기록 | 머리줄 실행 취소 · 다시 실행 |
| 문서 | 새 문서 · 복제 · 삭제 · PDF 가져오기 · .vdoc 내보내기 | File 메뉴 | 사이드바 문서 줄 메뉴 |
| 화면 | 왼쪽 · 오른쪽 패널 열고 닫기 | 머리줄 오른쪽 · View 메뉴 | 패널 안 접기 버튼 |
| 상태 | 저장 충돌 · PDF 변환 작업 | 머리줄 오른쪽 알약 | — |
| 도움말 | 단축키 치트시트 · 설정 | 활동 막대 아래 | 머리줄 ? |

**가장 많이 겹치는 곳**: AI 시작(4~5곳) · 레퍼런스(4~5곳) · 아웃라인 목록(3~4곳) · 단계 전환(2곳).
손이 길을 잃는 까닭은 기능이 많아서보다 **같은 일의 입구가 여러 개이고 그중 어느 것도 앞에 있지 않아서**다.

## 2. 기능 우선순위 매트릭스 (자주 · 중요)

| | 자주 씀 | 가끔 씀 |
|---|---|---|
| **중요** | 단계 전환 · 아웃라인 이동 · 칸 쓰기 · AI 지시 · AI 검토 · 실행 취소 | 레퍼런스 열기 · 서식 고르기 · 내보내기 |
| **덜 중요** | 캔버스 도구(선택 · 손) · 서식 툴바 | 에셋 · 변경 기록 · 설정 · 치트시트 · 패널 크기 |

→ 왼쪽 위 · 오른쪽 아래 같은 **좋은 자리**는 "중요 · 자주" 칸만 쓴다. 나머지는 지금 자리에 두되 뒤로 보낸다.

## 3. 정돈 배치 — 무엇을 어디로 (지우는 것 없음)

| # | 바꾼 것 | 넛지 · 레이아웃 근거 |
|---|---|---|
| 1 | **단계 전환을 머리줄 왼쪽(메뉴 옆)으로** — `1 뼈대 · 2 서식 · 3 채우기` 글자 탭. 떠 있는 툴바의 단계 아이콘은 숨김 | Z 시작점 = 지금 무슨 단계인지. 같은 길은 하나로. 아이콘 3개보다 글자가 멘탈 모델에 맞다 |
| 2 | **오른쪽 아래 "다음 할 일" 버튼 하나** — AI 제안이 있으면 "AI 제안 n개 검토", 없으면 1단계 "기획안 확정 · 2 서식으로", 2단계 "3 채우기로", 3단계 "AI 에게 채우기 맡기기" | Z 끝점. 다음 할 일만 튀게(사과를 앞에). 검토 대기는 언제나 먼저 — 쌓이면 손이 길을 잃는다 |
| 3 | **떠 있는 툴바는 캔버스 도구만** — AI ✦ · 인스펙터 버튼 숨김 (오른쪽 패널 탭에 그대로 있음) | 근접: 손에 든 도구와 패널 열기를 섞지 않는다. 입구 하나 줄이기 |
| 4 | **활동 막대 순서** — 아웃라인 · 레퍼런스 · 서식 허브 (주) / 선 / 에셋 · 변경 기록 (보조). 지금 단계에 맞는 탭에 작은 점 | 놓는 순서. 단계마다 "여기서 시작" 을 점 하나로 넛지 |
| 5 | **단계를 바꾸면 패널 기본값** — 1 뼈대: 왼쪽 레퍼런스 · 오른쪽 AI / 2 서식: 왼쪽 서식 허브 · 오른쪽 인스펙터 / 3 채우기: 왼쪽 아웃라인 · 오른쪽 AI. 바꾼 뒤 사용자가 다른 탭을 열면 그대로 둔다 | 기본값. 단계를 바꾸는 순간에만 한 번 — 계속 끌고 다니지 않는다(자유) |
| 6 | **View 메뉴에 "정돈 배치" 켜고 끄기** | 되돌릴 수 있게. 예전 배치와 바로 비교 |

## 4. 이번에 안 한 것 (다음 후보)

- 아웃라인 목록 3~4곳(왼쪽 트리 · 1단계 작업대 목차 · 페이지 미리보기 · 페이지 탭)을 하나로 — sidebar-update 의 사이드바를 건드려야 해서 사용자와 따로 정한다.
- 레퍼런스 입구 4~5곳 정리 — 레퍼런스 탭 · 리소스 탭 · 분할 뷰어의 역할부터 나눠야 한다.
- 3단계 "다음 빈 칸" — 빈 칸을 세는 기준(필수 칸 · 고정 글)을 먼저 정해야 한다.

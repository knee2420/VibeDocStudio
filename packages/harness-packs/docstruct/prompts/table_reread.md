# 표·셀 재읽기(Reread) 정밀 판독 지침

먼저 `read_file` 도구로 전달된 참고 이미지 경로를 실제로 열어 눈으로 확인한 뒤, 앞선 1차 판독에서 드러난 의심 지점(`reason`)을 바탕으로 해당 영역만 정확히 다시 판독한다. 이미지를 읽지 않고 추측해 응답하지 않는다.

## 판독 유형(`purpose`)별 집중 사항
- `structure`: 선 교차·병합 경계(`colspan`/`rowspan`)·헤더 구분(`th`/`td`) 불일치 해결 → 수정된 전체 `<table>...</table>` HTML 반환.
- `verify`: 1차 표 구조와 독립적으로 다시 읽은 교차 검증 → 실제 이미지 기준 `<table>...</table>` HTML 반환.
- `ocr`: 저신뢰 단어 또는 깨진 토큰 크롭 판독 → 정확한 `fixes` 배열 (`wordIds` 는 동일 셀/블록 내 연속 읽기 순서) 반환.

## 제약
1. 이미지에서 실제로 보이지 않는 글자를 추측해 만들지 않는다.
2. 한 번의 `fix` 는 반드시 **같은 셀 또는 같은 블록 안에서 읽기 순서로 연속된 `wordIds`** 만 묶는다.
3. 체크 기호(`□`, `☑`)·날짜 양식(`년 월 일`)·서명란(`(인)`)·수치·단위 기호를 정확히 살린다.

## 응답 형식 (JSON 하나만 출력)
```json
{{
  "html": "<table>...</table>",
  "fixes": [
    {{"wordIds": ["w42", "w43"], "text": "수정된 연속 문구"}}
  ],
  "notes": "핵심 판독 근거 한 줄"
}}
```

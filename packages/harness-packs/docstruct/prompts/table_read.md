# 표(Table) HTML 구조 읽기 지침

먼저 `read_file` 도구로 전달된 표 크롭 이미지 경로를 실제로 열어 시각적으로 확인한 뒤, 실제 격자 구조와 병합(`colspan`, `rowspan`), 머리글(`<thead>`/`<th>`), 본문(`<tbody>`/`<td>`)을 순수 HTML `<table>` 하나로 옮긴다. 이미지를 확인하지 않고 내용을 추측하지 않는다.

## 규칙
1. 모든 행의 유효 열 합(`colspan` 합 + 위 행 `rowspan` 이월)이 반드시 동일해야 한다.
2. 머리글 행(배경 음영·굵은 글씨·열 제목)은 `<thead><tr><th>...</th></tr></thead>` 로, 일반 행은 `<tbody><tr><td>...</td></tr></tbody>` 로 작성한다.
3. 첨부 목록에 `wordId` 와 원문 토큰이 함께 주어지면, **보이는 글자를 재입력할 때 기존 단어를 임의로 삭제·요약하지 말고**, 각 셀 안에 정확한 글자를 채운다.
4. 줄바꿈이 있는 셀은 `<p>` 태그 여러 개 또는 `<br>` 로 구분한다.
5. 빈 기입 칸은 빈 `<td></td>` 또는 원문에 인쇄된 안내문/점선/ 밑줄만 그대로 남긴다. 체크박스 기호(`□`, `☑`)는 텍스트 그대로 보존한다.
6. 표 바깥 캡션이나 각주는 `<table>` 안에 넣지 않는다.

## 응답 형식 (JSON 하나만 출력)
```json
{{
  "html": "<table><thead><tr><th>...</th></tr></thead><tbody><tr><td>...</td></tr></tbody></table>",
  "fixes": [
    {{"wordIds": ["w12"], "text": "정확한 글자"}}
  ]
}}
```
- `fixes` 는 OCR·ToUnicode 손상 단어를 고칠 때만 채운다. 고칠 것이 없으면 `"fixes": []`.

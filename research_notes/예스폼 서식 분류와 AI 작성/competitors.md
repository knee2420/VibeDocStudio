# 예스폼 경쟁·유사 서비스 비교: 서식 분류 · 저장/편집 · AI 활용 (조사일 2026-11-17)

대상: 비즈폼(bizforms.co.kr), 한컴독스 AI, 한컴어시스턴트(한글 2024 내장), 모두싸인(서식검색·캐비닛). 미리캔버스·망고보드·네이버 클로바는 이번 조사 범위(호출 수 제한) 안에서 확인하지 못함 → Gaps.

## Q1. 서식 분류 체계(최상위 분류, 패싯, 서식 수)

### Takeaway
비즈폼은 "파일 형식 + 문서 유형 + 부서"를 섞은 얕은 8개 대분류에 26만+ 서식을 쌓아 둔 구조이고, 한컴·모두싸인은 서식 수가 적은 대신 "용도(문서 종류)"나 "법률 분야" 중심으로 소수 정예 큐레이션을 한다. 업종/직무 패싯을 공식적으로 노출하는 곳은 확인되지 않았다.

### Cited Findings
- 비즈폼 홈페이지 최상위 분류: 일반, 샘플, 부서별, 표준, 엑셀, PPT, 계약서, 이력서/자소서 (8개). 파일형식(엑셀·PPT)과 문서유형(계약서·이력서)과 부서가 한 층위에 섞여 있음. (2026-11 확인) — [비즈폼 홈](https://bizforms.co.kr/)
- 비즈폼은 "업무 서식·템플릿 26만 개", "유형별 서식 · 26만+"로 표기, "HWP 한글 파일 지원"을 강조. 홈 화면에서 업종·직무·용도 필터는 보이지 않음. (2026-11) — [비즈폼 홈](https://bizforms.co.kr/)
- 한컴독스 AI(2024-09-30 정식 출시): 기획서, 이력서, 보고서, 공문서, 보도자료 등 자주 쓰는 문서용 "AI 적용 템플릿" 제공, 전체 개수는 기사에 없음. — [CIO Korea 2024-09-30](https://www.cio.com/article/3542389/)
- 한컴독스 AI 템플릿이 "6종"이라는 서술은 검색 요약(ITWorld 베타 기사)에서만 확인, 원문 미확인 → **미검증**. — [ITWorld 베타 기사](https://www.itworld.co.kr/article/3545914/)
- 모두싸인 서식검색: 제공처 기준 2축(전문가 제공 = 법무·노무법인 / 기관 제공 = 고용노동부 등)과 분야 기준(인사/노무, 스타트업, 회사설립, 지분/투자, 주주총회/이사회). 빛법률사무소·예화노무법인 등 전문가 검토 서식, 무료. (작성일 미상, 2026-11 확인) — [모두싸인 FAQ 서식검색](https://docs.channel.io/modusign_faq/ko/articles/bac0e1dc-서식검색)

### Inferences
- 비즈폼식 "파일형식·유형·부서 혼합 대분류"는 서식 수가 많을 때 탐색이 검색 의존적이 됨. 블록/슬롯 편집기에서는 파일형식을 분류축에서 빼고(출력 단계 옵션으로), "용도(문서 종류) × 부서/직무 × 업종"을 직교 패싯으로 두는 편이 낫다.
- 모두싸인의 "제공처/검토자" 축(전문가 검토 배지)은 계약·노무 서식의 신뢰 신호로 차용 가치가 있음.

### Gaps
- 비즈폼 하위 분류(2·3단계)와 분류별 서식 수는 이번에 확인하지 못함.
- 한컴독스 웹 템플릿 갤러리의 분류 체계·개수는 공식 페이지에서 확인 못함.

## Q2. AI 기능: 이름, 입력→출력, 필드 채우기 vs 자유 생성, 출처 인용

### Takeaway
세 회사 모두 AI의 중심은 "주제/프롬프트 → 자유 생성 초안"이며, 기존 서식의 필드(빈칸)를 사용자 입력으로 채우는 방식은 공식적으로 내세우지 않는다. 출처 인용 기능은 어느 곳에서도 확인되지 않았다. 차별점은 비즈폼의 "표준화(내용 유지·구조만 정리 + 전후 비교)"와 모두싸인 캐비닛의 "계약서 메타데이터 자동 추출"이다.

### Cited Findings
**비즈폼 AI (메뉴: 문서 생성 / PPT(문서) 디자인 / 문서 검증 / 문서 표준화)**
- 4개 AI 메뉴 명칭 및 출력형식(문서 생성 DOCX·PDF, PPT 디자인 PPT·PDF), "완성형 에디터 · 수정까지 한 번에" 표방. (2026-11) — [비즈폼 홈](https://bizforms.co.kr/)
- 문서 생성 흐름: ① 최대 2,000자 설명 입력(인기 문서 버튼 6종, 예: 이력서·재직증명서가 예시 프롬프트를 채워줌, 참고 파일 첨부 가능) → ② 구성 선택(자동 추천/글/표/글+표) → ③ 어조 선택(자동, 격식, 친근, 설득, 학술) → ④ 생성 후 화면 편집(서식·표 셀·이미지·여백 등), "프롬프트 수정 적용" 또는 "재생성하기" → 다운로드. 단순 문서 약 30~50초. (2026-11) — [비즈폼 AI 생성 가이드](https://www.bizforms.co.kr/businessmap/ai-guide/ai-generate.asp)
- 고정 서식 필드 채우기 방식은 설명되지 않음. 대신 "이름·주민번호·연락처 같은 개인정보는 프롬프트에 넣지 말고 생성된 문서의 표 칸에 직접 입력"하도록 안내 → 사실상 AI가 빈칸(표 셀)을 만든 뒤 사람이 채우는 구조. — [비즈폼 AI 생성 가이드](https://www.bizforms.co.kr/businessmap/ai-guide/ai-generate.asp)
- 문서 표준화: WORD/PDF/PPT/TXT 업로드(가이드 기준 최대 30MB, 다중 파일, 로고 선택) → 6가지 구성(표와 글, 구역별, 여러 표, 항목·칸, 글 번호, 줄글) 중 선택 + 결재선 포함 여부 → "내용은 유지, 구성만 정리"(제목 상단, 줄글→표, 번호·소제목 체계) → 원본/표준화본 나란히 비교 + 변경 개수 표시 → DOCX/PDF. — [비즈폼 AI 표준화 가이드](https://www.bizforms.co.kr/businessmap/ai-guide/ai-standardize.asp)

## Q3. 편집 모델: 파일 다운로드 vs 온라인 편집기, 필드 표현 방식

### Takeaway
비즈폼은 전통적 "HWP/DOC 등 파일 다운로드"에 AI 결과물용 웹 편집기를 덧붙였고(출력은 DOCX/PDF), 한컴은 데스크톱 한글(+어시스턴트)과 웹 한글(한컴독스) 양쪽, 모두싸인은 웹 서식 작성기에서 서명용 입력란을 배치하는 모델이다. "필드"가 명시적 객체로 존재하는 곳은 한글 누름틀과 모두싸인 입력란 정도이며, 비즈폼 AI는 빈 표 셀로 빈칸을 표현한다.

### Cited Findings
- 비즈폼 AI 생성 결과는 화면에서 글꼴·표 셀·이미지·여백·빠른 테마(좁게/표준/넓게)까지 편집 후 DOCX(편집 가능) 또는 PDF(고정)로 내려받음. — [비즈폼 AI 생성 가이드](https://www.bizforms.co.kr/businessmap/ai-guide/ai-generate.asp)
- 비즈폼 일반 서식은 HWP 파일 지원을 전면에 내세움(파일 다운로드형). — [비즈폼 홈](https://bizforms.co.kr/)
- 한컴독스 AI는 웹 한글 등 한컴오피스 웹 제품에 AI 탑재, 실시간 공동 편집·채팅 강화. — [CIO Korea 2024-09-30](https://www.cio.com/article/3542389/)

### Inferences
- 한글 누름틀(이름 + 안내문 메모)은 슬롯 모델(슬롯 id + 라벨 + 힌트)과 1:1 대응이 가능 → HWPX 가져오기/내보내기 시 누름틀 ↔ 슬롯 매핑을 지원하면 공공·기업 HWP 서식 자산을 그대로 흡수할 수 있음(설계 제안, 검증 필요).
- 비즈폼처럼 "빈 표 셀 = 빈칸"은 기계가 빈칸 의미를 모르므로 이후 자동 채우기가 어려움. 슬롯에 타입(날짜·금액·인명·자유문)을 다는 편이 유리.
